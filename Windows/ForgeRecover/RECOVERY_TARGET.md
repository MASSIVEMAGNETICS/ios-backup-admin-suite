# Recovery maturity gates

- [x] Existing-password encrypted backup unlock into a derived working copy
- [x] WAL salt/checksum validation and transaction visibility
- [x] Freelist leaf/trunk free-space scanning
- [x] B-tree freeblock/unallocated-region scanning
- [x] Explicit fragment evidence classifications
- [x] Controlled known-positive / known-negative corpus harness
- [ ] Real authorized iOS corpus populated and independently validated
- [ ] Schema-aware SQLite record/serial-type reconstruction
- [ ] Overflow-page row reconstruction
- [ ] Artifact correlation back to SMS/iMessage/call/contact rows

A checked engineering capability is not equivalent to a large-corpus validation claim. The final four gates remain evidence-dependent work.
